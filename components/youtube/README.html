YouTube App

Intentional YouTube queue management with priority-based viewing and knowledge capture.

Purpose

The YouTube app transforms reactive YouTube browsing into deliberate content consumption. Instead of algorithm-driven recommendations, maintain a prioritized queue of videos aligned with your learning goals and interests.

Key benefits:

  • Priority-based queue - Always know what to watch next
  • Categorized content - Organize by learning, entertainment, research
  • Knowledge capture - Take notes and rate watched content
  • Framework integration - Fits existing Personal OS workflows

Quick Start

Adding videos to the queue

Ask Claude to add a video using natural language:

add youtube https://youtu.be/dQw4w9WgXcQ @learning high
queue video https://youtube.com/watch?v=abc123 @entertainment
add to youtube queue https://youtu.be/xyz789 @tutorial p1

Supported parameters:

  • URL (required) - YouTube video URL
  • Category via @ prefix - learning, entertainment, research, tutorial, news, music, podcast, other
  • Priority - high/p1, medium/p2, low/p3, critical/p0
  • Tags via # prefix - any custom tags

Viewing the queue

Open components/youtube/youtube-base.base in Obsidian to see:

  • Watch Next - Queued items sorted by priority
  • By Category - Items grouped by content type
  • Currently Watching - Videos in progress
  • Watched - Completed with notes and ratings
  • All Items - Complete list with filtering

Workflows

Adding a new video

  1. Share URL from YouTube to Claude with category and priority
  2. Claude extracts video-id, creates file with ULID filename
  3. Optionally add title, channel, duration manually (Phase 1) or auto-fetch (Phase 3)
  4. Video appears in “Watch Next” view

Watching a video

  1. Open “Watch Next” view, pick highest priority item
  2. Change status to watching
  3. Watch video, add notes in the file
  4. Change status to watched, optionally add rating
  5. Video moves to “Watched” view

Reviewing watched content

  1. Open “Watched” view
  2. Review notes and ratings
  3. Search for insights across watched videos
  4. Link to other notes or projects as needed

URL Parsing

Claude extracts the video-id from various YouTube URL formats:

  • https://youtube.com/watch?v=dQw4w9WgXcQ
  • https://www.youtube.com/watch?v=dQw4w9WgXcQ
  • https://youtu.be/dQw4w9WgXcQ
  • https://youtube.com/embed/dQw4w9WgXcQ

The video-id is always 11 characters: dQw4w9WgXcQ
